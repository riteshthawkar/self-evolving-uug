\section{Computational Cost Analysis}
\label{sec:sup_cost}

Table~\ref{tab:computational_cost} breaks down the computational overhead of each framework component. The self-evolving framework introduces moderate training cost relative to the base model pretraining, with the generation loop accounting for the majority of computation due to the image synthesis forward passes. Notably, the STE computation adds negligible overhead as it requires only a single greedy forward pass, compared to the $N{=}7$ forward passes needed for prompt-perturbed self-consistency.

\section{Per-Model Training Dynamics}
\label{sec:sup_per_model_dynamics}

Figure~\ref{fig:sup_per_model_dynamics} presents the training dynamics for each backbone architecture separately. Despite fundamentally different generation mechanisms (diffusion-based denoising for BLIP3o-8B, flow-matching for BAGEL, and autoregressive token prediction for VARGPT), all three models exhibit qualitatively similar training dynamics, providing additional evidence for the model-agnostic nature of the framework.

\noindent\textbf{Model-specific adaptations.}
\begin{itemize}
  \item \textbf{BLIP3o-8B (diffusion):} The generation policy gradient is applied to the text conditioning that drives the denoising process. Image generation uses $\text{--}$ denoising steps with classifier-free guidance scale $\text{--}$.
  \item \textbf{BAGEL (flow-matching):} The generation policy gradient is applied to the text conditioning of the flow-matching decoder. The VAE encoder is frozen. Image generation uses $\text{--}$ flow steps.
  \item \textbf{VARGPT (autoregressive):} The generation policy gradient is applied to the discrete token prediction sequence. The codebook is frozen. Image generation produces $\text{--}$ tokens per image.
\end{itemize}

\noindent\textbf{Diagnostic questions for QA fidelity.}
We use $M{=}\text{--}$ diagnostic questions per image, covering object identity, color, count, spatial relationships, scene context, and action/state descriptions. Questions are generated by the proposer in a separate generation pass and cached for the generation step.

\noindent\textbf{Prompt framings for self-consistency.}
The $N{=}7$ prompt framings are fixed throughout training. Each framing reformulates the question with different instructional phrasing while preserving the question content. Example framings include: analytical perspective (``Carefully analyze the image and answer:''), observational perspective (``Based on what you observe in the image:''), and concise directive (``Answer briefly:'').
