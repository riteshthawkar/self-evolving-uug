
\section{Method}
\label{sec:method}

\subsection{Problem Formulation}
\label{sec:problem}

Let $\mathcal{M}_\theta$ denote a pretrained unified model parameterized by $\theta$ supporting visual understanding $\mathcal{U}: (\mathcal{I}, q) \mapsto a$ and image generation $\mathcal{G}: t \mapsto \hat{\mathcal{I}}$. Given only an unlabeled image collection $\mathcal{D} = \{\mathcal{I}_1, \ldots, \mathcal{I}_N\}$ with no associated captions, question-answer pairs, or quality annotations, our goal is to learn $\Delta\theta$ such that $\mathcal{M}_{\theta + \Delta\theta}$ improves on both $\mathcal{U}$ and $\mathcal{G}$, subject to: (C1)~no human annotations or curated instruction data at any stage, (C2)~no external reward models or pretrained evaluators, and (C3)~no assumptions about internal architecture, operating solely through text generation and image synthesis interfaces.

\subsection{Framework Overview}
\label{sec:overview}

We decompose the frozen backbone into three functional roles via lightweight LoRA adapters~\cite{hu2022lora}:

\begin{itemize}
    \item \textbf{Proposer} ($\phi_p$): generates open-ended visual questions about an input image.
    \item \textbf{Solver} ($\phi_s$): answers visual questions using the understanding capability.
    \item \textbf{Generator} ($\phi_g$): synthesizes images from textual descriptions using the generation capability.
\end{itemize}

Each adapter modifies a small fraction of parameters while $\theta$ remains frozen, ensuring all three roles share pretrained representations and independent optimization does not destabilize the base model. Training alternates between \emph{understanding steps} (updating proposer and solver) and \emph{generation steps} (updating generator). The Solver plays a dual role: it is a learner within the understanding loop and an internal evaluator within the generation loop, coupling understanding improvement directly to generation quality without external supervision. Figure~\ref{fig:framework} provides a visual overview.

\subsection{Self-Consistent Understanding}
\label{sec:understanding}

For each sampled image $\mathcal{I}$, the Proposer generates a question $q \sim \pi_{\phi_p}(\cdot \mid \mathcal{I})$. Rather than sampling multiple answers via temperature variation, we evaluate the Solver under $N$ semantically equivalent but syntactically distinct prompt framings $\{\rho_1, \ldots, \rho_N\}$, each preserving question content with different instructional phrasing. The Solver generates one answer per framing:
\begin{equation}
    a_i = \text{Solver}_{\phi_s}(\mathcal{I}, \rho_i(q)), \quad i = 1, \ldots, N.
\end{equation}
The majority answer is $a^* = \arg\max_{a} |\{i : a_i = a\}|$, and the self-consistency entropy is:
\begin{equation}
    H_{\text{sc}} = -\sum_{c} p_c \ln p_c, \quad p_c = \frac{|\{i : a_i = c\}|}{N}.
    \label{eq:sample_entropy}
\end{equation}
This measures the \emph{robustness} of understanding rather than stochastic variation: a model that genuinely comprehends the visual content produces consistent answers regardless of framing ($H_{\text{sc}} \approx 0$), while fragile understanding yields conflicting answers ($H_{\text{sc}} > 0$).

\paragraph{Solver Token Entropy (STE).}
A key limitation of sample-level self-consistency is that $H_{\text{sc}} = 0$ when all responses agree, even if internal confidence is low. Questions where the Solver answers correctly under all framings but with substantial hesitation are the most useful for curriculum learning because they lie near the competence frontier. We introduce STE, a continuous difficulty measure from a single greedy forward pass. Let $\mathbf{p}_t \in \mathbb{R}^{|V|}$ denote the softmax distribution at decoding step $t$, with per-token entropy $H_t = -\sum_{v} p_{t,v} \ln p_{t,v}$. STE is:
\begin{equation}
    \hat{H} = \max_{t \in \{1, \ldots, K\}} H_t.
    \label{eq:ste}
\end{equation}
The maximum captures the point of greatest internal uncertainty during answer generation. Even if most tokens are produced confidently, a single high-entropy token indicates the question probes a decision boundary. To make STE comparable across questions, we normalize via a self-calibrating quantile rank within a rolling window $\mathcal{W}$:
\begin{equation}
    d_{\text{ste}} = \frac{|\{h \in \mathcal{W} : h < \hat{H}\}|}{|\mathcal{W}|},
    \label{eq:ste_quantile}
\end{equation}
yielding $d_{\text{ste}} \in [0, 1]$ that adapts to the evolving difficulty distribution without manual thresholds. STE is computed from a single greedy pass, adding negligible overhead.

\paragraph{Proposer optimization.}
We define the Proposer reward as:
\begin{equation}
    R_p = w_{\text{ste}} \cdot d_{\text{ste}} + w_{\text{sc}} \cdot r_{\text{sc}},
    \label{eq:proposer_reward}
\end{equation}
where $r_{\text{sc}}$ is a hybrid reward blending a Gaussian component centered on an adaptive entropy target with a local informativeness score. The default weights ($w_{\text{ste}} = 0.70$, $w_{\text{sc}} = 0.30$) ensure the Proposer receives meaningful gradients even when all Solver responses agree. The Proposer is updated via GRPO: at each step, it generates $K$ candidate questions per image, each scored by $R_p$. Advantages are computed using bucket-stratified EMA baselines that separate easy, medium, and hard difficulty tiers, maintaining consistent pressure toward harder questions.

\paragraph{Solver optimization.}
The Solver is updated via KL-regularized REINFORCE. Each response is rewarded based on agreement with the majority and overall question difficulty: positive reward for majority-agreeing answers on non-trivial questions, penalty for minority answers, and a small penalty for unanimous agreement on trivially easy questions. The reward is modulated by a verbosity penalty to discourage excessively long answers. Both the Proposer and Solver losses include adaptive KL regularization against the frozen reference model to prevent divergence:
\begin{equation}
    \mathcal{L}_A = -\mathbb{E}\!\left[(R_A - b_A) \frac{1}{T_A}\sum_{t=1}^{T_A}\log \pi_A(y_t \mid h_t)\right] + \beta_A \cdot \overline{\text{KL}}_A,
    \label{eq:policy_loss}
\end{equation}
where $A \in \{\text{Proposer}, \text{Solver}\}$, $b_A$ is an EMA baseline, and $\beta_A$ is an adaptive KL coefficient.

\paragraph{Training insight.}
Early in training, Solver outputs can be highly variable, making binary or thresholded rewards sparse and unstable. The STE-augmented Proposer reward and graded Solver reward provide dense feedback even under partial agreement, preventing cold-start stagnation. This naturally induces a curriculum: as the Solver becomes more reliable, the Proposer shifts toward higher-value, boundary-level questions instead of collapsing to trivial prompts.


\subsection{Generation Assessment via Internal Evaluation}
\label{sec:generation}

The generation loop uses the Solver as an internal evaluator, providing the training signal for the Generator without external reward models. We combine two complementary scoring mechanisms that address each other's failure modes.

\paragraph{QA fidelity scoring.}
Given an image $\mathcal{I}$ and generation prompt $t$, the Solver generates reference answers to $M$ diagnostic questions on the real image: $a^{\text{ref}}_j = \text{Solver}_{\phi_s}(\mathcal{I}, q_j)$. The Generator produces $\hat{\mathcal{I}} = \text{Generator}_{\phi_g}(t)$, and the Solver answers the same questions on the synthesized image: $\hat{a}_j = \text{Solver}_{\phi_s}(\hat{\mathcal{I}}, q_j)$. The fidelity score measures agreement:
\begin{equation}
    S_{\text{fid}} = \frac{1}{M} \sum_{j=1}^{M} \mathbb{1}[\hat{a}_j = a^{\text{ref}}_j].
    \label{eq:fidelity}
\end{equation}
This captures whether the generated image preserves specific semantic content. As the Solver improves through understanding training, its reference answers become more accurate and diagnostic questions probe finer distinctions, naturally coupling understanding quality to generation training.

\paragraph{Cycle-consistent captioning.}
QA fidelity only evaluates the specific attributes that diagnostic questions probe. A generated image could answer all diagnostic questions correctly while exhibiting holistic failures (incoherent composition, context omission) that no question happened to target. The Solver generates a caption $\hat{t}$ of the synthesized image, and cycle consistency measures global alignment:
\begin{equation}
    S_{\text{cyc}} = \tfrac{1}{2}\,\text{sim}(f(t), f(\hat{t})) + \tfrac{1}{2}\,\text{sim}_{\text{vl}}(\hat{\mathcal{I}}, t),
    \label{eq:cycle}
\end{equation}
where $f(\cdot)$ denotes a text embedding function and $\text{sim}_{\text{vl}}$ denotes visual-linguistic similarity from the model's own frozen encoder. The first term measures whether the generated image yields a caption aligned with the original prompt; the second evaluates visual-textual alignment at the representation level. Both use the model's internal representations rather than external scoring models.

\paragraph{Generator optimization.}
The combined generation reward is:
\begin{equation}
    R_g = w_{\text{fid}} \cdot S_{\text{fid}} + w_{\text{cyc}} \cdot S_{\text{cyc}} + w_{\text{div}} \cdot S_{\text{div}} - w_{\text{ctr}} \cdot S_{\text{ctr}},
    \label{eq:gen_reward}
\end{equation}
where $S_{\text{div}}$ encourages visual diversity and $S_{\text{ctr}}$ penalizes internal contradictions. In practice, we normalize the positive mixture weights $(w_{\text{fid}}, w_{\text{cyc}}, w_{\text{div}})$ and use $w_{\text{ctr}}$ as a separate penalty coefficient. The Generator is updated via KL-regularized REINFORCE using the same form as Eq.~\eqref{eq:policy_loss}. The generation pathway is treated abstractly: for diffusion models the policy gradient applies to text conditioning; for autoregressive models it applies to discrete token prediction. This abstraction enables identical optimization across architecturally distinct unified models.

\paragraph{Coupling design.}
The understanding and generation loops are deliberately kept loosely coupled through the Solver's dual role. The Proposer is not directly influenced by generation quality, as mixing generation-quality signals into its reward would create conflicting gradients. Instead, the coupling flows indirectly: as the Proposer generates harder questions and the Solver improves, the Solver's evaluations of generated images become more discriminative, providing a stronger signal for the Generator.
