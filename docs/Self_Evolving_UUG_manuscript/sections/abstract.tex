\begin{abstract}
Unified understanding and generation models that perform both visual understanding and image generation within a single architecture represent a promising frontier, yet their post-pretraining improvement remains heavily dependent on large-scale, task-specific human annotations — separate supervision for comprehension and generation alike. We present a self-evolving training framework that enables a unified VLM to autonomously improve both its understanding and generation capabilities using only unlabeled images and its own internal feedback, requiring no human annotation whatsoever.

Our framework decomposes the unified model into three co-evolving roles via lightweight LoRA adapters sharing the same frozen backbone: a Proposer that crafts visual questions about unlabeled images, a Solver that answers them using the model's understanding pathway, and a Generator that synthesizes images through the model's generation pathway. The key insight is Solver Token Entropy (STE) — the token-level prediction uncertainty from a single greedy solver forward pass — which provides a continuous, compute-efficient difficulty signal without requiring expensive multi-sample consensus. The proposer is optimized via policy gradients to maximize this uncertainty, autonomously discovering questions at the frontier of the model's comprehension. As the solver strengthens, the proposer must escalate difficulty to sustain high entropy, forming a self-reinforcing curriculum that simultaneously drives improvement in both understanding and generation — all within one unified architecture.

Unlike prior self-training methods that address understanding or generation in isolation, our approach exploits the shared representations of unified VLMs to create a single, annotation-free improvement loop across both modalities. Experiments demonstrate that the framework successfully induces progressive difficulty escalation and meaningful internal disagreement from a cold start, establishing self-evolved curricula as a scalable path for unsupervised refinement of unified vision-language models.
\end{abstract}
