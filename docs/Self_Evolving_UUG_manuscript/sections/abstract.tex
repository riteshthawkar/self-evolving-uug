\begin{abstract}
Unified vision language models that perform both visual understanding and image generation within a single architecture have emerged as a promising paradigm. However, improving both capabilities after pretraining typically requires large-scale, task-specific human annotations for each modality, limiting scalability and introducing annotation bias. In this work, we propose a self-evolving training framework that enables a unified model to autonomously improve both understanding and generation using only unlabeled images, without any human annotations or external reward models.

Our framework instantiates three co-evolving roles from a single frozen backbone using lightweight LoRA adapters: a proposer that generates visual questions about unlabeled images, a solver that answers them through the understanding pathway, and a generator that synthesizes images through the generation pathway. The training signal is derived entirely from self-consistency: the solver's responses are evaluated across diverse prompt perturbations, where robust agreement indicates confident understanding and disagreement reveals the boundary of the model's competence. To address the limitation that self-consistency yields no gradient when all responses agree, we introduce Solver Token Entropy (STE), a continuous difficulty measure extracted from token-level prediction uncertainty in a single greedy forward pass, which guides the proposer toward generating progressively harder questions as training advances. The solver simultaneously serves as an internal evaluator for the generator, scoring synthesized images through question answering fidelity and cycle consistent captioning, thereby coupling understanding quality directly to the generation training signal without external supervision.

The framework is designed to be model-agnostic at the algorithmic level, relying on role decomposition and cyclic self-supervised optimization rather than architecture-specific components. We validate this generality by implementing the approach on three architecturally distinct unified models spanning diffusion-based, flow-matching, and autoregressive discrete-token generation paradigms. Experiments demonstrate that the framework induces progressive difficulty escalation and meaningful self-consistency disagreement from a cold start, establishing unsupervised self-evolution as a scalable direction for refining unified understanding and generation models.
\end{abstract}
