\begin{abstract}
Unified models that integrate visual comprehension and image synthesis within a single architecture have emerged as a promising paradigm. While pretraining establishes foundational capabilities, substantial post-training is needed to refine both understanding and generation. Existing post-training approaches rely on large-scale human annotations, curated instruction data, or external reward models for each modality, limiting scalability and introducing annotation bias. We propose a self-evolving training framework that enables a unified model to autonomously improve both understanding and generation using only unlabeled images, without any human annotations or external reward models. The framework decomposes a frozen backbone into three co-evolving roles via lightweight LoRA adapters: a proposer that generates visual questions, a solver that answers them, and a generator that synthesizes images. The learning signal emerges from self-consistency: solver responses are evaluated across diverse prompt perturbations, where disagreement reveals the model's competence boundary. We introduce Solver Token Entropy (STE), a continuous difficulty measure from token-level prediction uncertainty, which guides the proposer toward progressively harder questions even when all responses agree. The solver simultaneously evaluates generated images through QA fidelity scoring and cycle-consistent captioning, coupling understanding quality directly to the generation training signal. The framework is model-agnostic and we validate it on three architecturally distinct unified models spanning diffusion-based, flow-matching, and autoregressive generation paradigms, demonstrating consistent bidirectional improvements across both capabilities.
\end{abstract}
