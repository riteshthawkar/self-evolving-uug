\begin{abstract}
    Unified multimodal models that jointly perform visual understanding and image generation still rely on curated supervision during post-training. We propose a self-evolving framework in which three internal roles (a Proposer, Solver, and Generator) collaborate using only unlabeled images. Training is driven by internal consistency: we introduce Solver Token Entropy (STE), a token-level difficulty signal that remains informative when sample-level consistency collapses, and a multi-scale generation evaluation combining QA fidelity with cycle-consistent captioning that couples understanding quality to generation supervision. The same role/reward recipe applies across diffusion (BLIP3o), flow matching (BAGEL), and autoregressive (VARGPT-v1.1) paradigms, with the Generator adapter objective instantiated as token-policy optimization for autoregressive models and reward-weighted denoising for diffusion/flow models. Across nine benchmarks, our method consistently improves over base models, achieving $+3.5\%$ MMMU and 82\%$\to$85\% GenEval on BAGEL-7B. Code and models will be publicly released.
\end{abstract}
