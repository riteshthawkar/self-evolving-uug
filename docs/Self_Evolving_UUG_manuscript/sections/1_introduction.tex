\section{Introduction}

Unified understanding and generation models that integrate visual comprehension and image synthesis within a single architecture have made substantial progress in recent years~\citep{chen2025januspro, wang2024emu3, qu2025tokenflow, deng2025bagel}. By sharing representations across both tasks, these models create the potential for cross-modal synergy: visual comprehension can inform more faithful generation by grounding synthesis in fine-grained scene understanding, while generative experience can enrich perceptual reasoning through exposure to the causal structure of visual content. However, despite architectural convergence, the initial pretraining optimizes a broad distributional objective, and the resulting models exhibit substantial headroom for post-training refinement on both capabilities.

Closing this gap faces a supervision bottleneck. The prevailing post-training approach relies on curated, task-specific annotations: visual question-answer pairs for understanding, aesthetic preference labels for generation, or both. This paradigm suffers from three structural limitations. First, annotation cost scales linearly with data volume and must be replicated per modality. Second, human-curated labels introduce systematic biases that narrow the model's competence to well-represented distributions. Third, supervised signals for understanding and generation are typically designed in isolation, treating the two modalities as independent objectives rather than exploiting their mutual dependence. Recent self-supervised methods have begun to address these limitations through role-based self-play~\citep{su2025unigame, han2026unicorn}, dual-likelihood rewards~\citep{hong2025dualselfrewards}, and reinforcement-based optimization~\citep{mao2025unirl}, but each introduces additional dependencies such as auxiliary judge components, architecture-specific interfaces, supervised fine-tuning stages, or single-scalar rewards that capture only one dimension of quality.

In this work, we investigate a fundamental question: \emph{Can a unified understanding and generation model autonomously improve both capabilities using only unlabeled images, without human annotations, curated data, or external reward models?} To this end, we propose a self-evolving training framework that decomposes a frozen pretrained backbone into three co-evolving roles via lightweight LoRA adapters~\citep{hu2022lora}: a \textbf{Proposer} that generates visual questions about unlabeled images, a \textbf{Solver} that answers them through the understanding pathway, and a \textbf{Generator} that synthesizes images through the generation pathway. The learning signal emerges from self-consistency: the Solver answers each question under multiple semantically distinct prompt framings, and the agreement pattern provides rewards for both the Proposer and the Solver. We introduce Solver Token Entropy (STE), a continuous difficulty measure from token-level prediction uncertainty in a single greedy forward pass, which resolves a critical limitation of self-consistency: when all Solver responses agree, the sample-level entropy is identically zero regardless of the model's internal confidence. STE provides a continuous gradient across the full difficulty spectrum, enabling the Proposer to generate progressively harder questions that track the Solver's competence boundary. The Solver simultaneously evaluates generated images through QA fidelity scoring and cycle-consistent captioning, coupling understanding quality directly to the generation training signal. As the Solver improves on harder questions, its evaluations become more discriminative, creating a virtuous cycle where understanding improvement naturally drives generation improvement.

In summary, our main contributions are:
\begin{itemize}
    \item We propose a self-evolving training framework that improves both understanding and generation of unified models using only unlabeled images, eliminating the need for human annotations, curated data, and external reward models at any stage.
    \item We introduce Solver Token Entropy (STE), a continuous difficulty measure from token-level prediction uncertainty, which resolves the degenerate-signal limitation of self-consistency and enables effective curriculum learning from a cold start.
    \item We design a multi-scale generation assessment combining QA fidelity scoring with cycle-consistent captioning, using the Solver as an internal evaluator to couple understanding quality directly to the generation training signal.
    \item We demonstrate model-agnostic generality by applying the same algorithm with identical hyperparameters across three architecturally distinct unified models spanning diffusion-based, flow-matching, and autoregressive generation paradigms.
\end{itemize}
