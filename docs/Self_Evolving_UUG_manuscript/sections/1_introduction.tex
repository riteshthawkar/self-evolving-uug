\section{Introduction}

Unified understanding and generation models that integrate visual comprehension and image synthesis within one architecture have advanced rapidly~\citep{chen2025januspro, wang2024emu3, qu2025tokenflow, deng2025bagel}. Shared representations create cross-task synergy: understanding can improve generation faithfulness, and generation can strengthen perceptual reasoning. However, pretraining alone does not close this gap. Substantial headroom remains for post-training on both capabilities.

Closing this gap faces a supervision bottleneck. Most post-training pipelines rely on curated annotations: VQA-style labels for understanding, preference labels for generation, or both. This paradigm has three limitations. Annotation cost scales with data volume and must be repeated per modality. Human labels introduce distributional bias. Finally, understanding and generation are usually optimized separately, which weakens cross-task learning. Recent self-supervised methods partially address this through role-based self-play~\citep{su2025unigame, han2026unicorn}, dual-likelihood rewards~\citep{hong2025dualselfrewards}, and reinforcement-based optimization~\citep{mao2025unirl}. However, many still require auxiliary judges, architecture-specific interfaces, supervised stages, or single-scalar rewards with limited coverage.

In this work, we ask: \emph{Can a unified understanding and generation model improve both capabilities using only unlabeled images, without human annotations, curated data, or external reward models?} We propose a self-evolving framework that decomposes a frozen backbone into three LoRA-based roles~\citep{hu2022lora}: a \textbf{Proposer} that generates visual questions, a \textbf{Solver} that answers them, and a \textbf{Generator} that synthesizes images. Learning is driven by internal consistency. The Solver answers each question under diverse prompt framings, and agreement patterns provide rewards for Proposer and Solver updates. We introduce Solver Token Entropy (STE), a continuous difficulty signal computed from one greedy forward pass. STE resolves a key degeneracy of sample-level consistency: if all responses agree, sample entropy becomes zero regardless of internal uncertainty. This gives the Proposer a usable curriculum signal across the full difficulty range. For generation, the Solver evaluates outputs using QA fidelity and cycle-consistent captioning, directly coupling understanding quality to the generation signal. As Solver quality improves, generation supervision becomes sharper, creating a positive feedback loop.

Across BLIP3o, BAGEL, and VARGPT$_{1.1}$, this single framework yields consistent within-backbone gains over base checkpoints: +2.0 to +3.5 points on understanding benchmarks and +0.03 GenEval on all three backbones. These results indicate that self-evolving post-training can improve both capabilities without additional supervision while transferring across diffusion, flow-matching, and autoregressive paradigms.

In summary, our main contributions are:
\begin{itemize}
    \item We propose a self-evolving training framework that improves both understanding and generation of unified models using only unlabeled images, eliminating the need for human annotations, curated data, and external reward models at any stage.
    \item We introduce Solver Token Entropy (STE), a continuous difficulty measure from token-level prediction uncertainty, which resolves the degenerate-signal limitation of self-consistency and enables effective curriculum learning from a cold start.
    \item We design a multi-scale generation assessment combining QA fidelity scoring with cycle-consistent captioning, using the Solver as an internal evaluator to couple understanding quality directly to the generation training signal.
    \item We demonstrate model-agnostic generality on three unified backbones: diffusion, flow matching, and autoregressive generation. We use one self-evolving algorithm and a matched training recipe across all three.
\end{itemize}
